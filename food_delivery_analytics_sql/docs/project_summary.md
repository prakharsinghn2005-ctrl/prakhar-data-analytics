# Project Summary

## Objective
Use SQL to understand food delivery business performance across customers, restaurants, orders, cuisines and delivery operations.

## Main Analysis Areas
1. Revenue & order KPIs
2. City performance
3. Restaurant performance
4. Cuisine and menu-item performance
5. Customer behavior and segmentation
6. Delivery performance
7. Cancellation and rating analysis
8. Payment method analysis
9. Discount analysis
10. Monthly growth and weekday/weekend trends

## Portfolio Talking Points
- Built a relational SQL data model with five connected tables.
- Wrote 20 business-focused SQL queries.
- Used joins, CTEs, aggregations and window functions.
- Created customer segmentation using CASE logic.
- Used date functions for monthly and hourly trend analysis.
- Analyzed operational KPIs such as cancellation rate and delivery time.
